# Simple Coffee — Посібник користувача

У цьому посібнику пояснюється, як переглядати товари, керувати кошиком, оформлювати замовлення та користуватися адміністративними інструментами.

---

## 1. Функції для клієнтів

### Перегляд товарів
* Перейдіть на сторінку **Товари** (**Products**) за допомогою верхньої навігаційної панелі.
* Перегляньте доступні товари, включаючи їхні зображення, описи та ціни.

### Управління кошиком
* Введіть бажану кількість поруч із будь-яким товаром і натисніть **Додати до кошика** (**Add to cart**).
* Перейдіть на сторінку **Кошик** (**Cart**), щоб переглянути вибрані товари та загальну вартість замовлення.
* Щоб прибрати товар із замовлення натисніть на круглу кнопку з червоним хрестом поруч із окремим товаром у кошику.

### Оформлення замовлення
* Якщо ви задоволені своїм вибором на сторінці **Кошик** (**Cart**), натисніть **Оформити замовлення** (**Make Transaction**).
* Перегляньте історію попередніх замовлень безпосередньо на сторінці **Обліковий запис** (**Account**).

---

## 2. Функції адміністратора

> **Примітка:** Для доступу адміністратора необхідний обліковий запис із правами адміністратора.

### Управління товарами в каталозі
* **Створити товар:** На сторінці **Адміністратор** (**Admin**) скористайтеся верхньою формою, щоб ввести назву товару, опис, ціну та завантажити файл із зображенням. Натисніть **Створити товар** (**Create Product**).
* **Редагувати товар:** Прокрутіть сторінку **Адміністратор** (**Admin**) до будь-якого товару, відредагуйте його властивості (назву, ціну, зображення) та натисніть **Зберегти зміни** (**Save Changes**).
* **Видалити товар:** Натисніть червону кнопку **Видалити товар** (**Delete Product**) на картці товару, щоб назавжди видалити його з магазину.
