# Simple-Coffee

## Опис
Онлайн система онлайн замовлень для кафе

## Документація

### Текстова документація

#### ~ Текстова документація
Текстова документація доступна у папці ```docs/``` цього проєкту

```USER-DOCS.md``` - документація для користувачів

```TECH-DOCS.md``` - документація для розробників

### Інструкція з встановлення

#### ~ Перед встановленням
Переконайтеся, що у вас встановлено все, що в списку нижче:
```
  1. Node.js версії 26.4.1 і вище
  2. MongoDB та налаштовано на порт 27017
  3. Angular CLI - глобально
```

#### ~ Встановлення та запуск
Для встановлення та запуску зробіть наступні дії:
  1. Скопіюйте даний репозиторій на локальну машину командою:
      ```bash
      https://github.com/ArtVitLobanov/Simple-Coffee.git
      ```
  2. Перейдіть у скопійнований репозитарій командою:
       ```bash
       cd Simple-Coffee
       ```
  3. Для налаштування 'back-end' відкрийте консоль у директорії репозитарію та виконайте наступні команди:
      ```bash
      cd back-end
      npm install
      npm run dev
      ```
  4. Для налаштування 'front-end' відкрийте іншу консоль та виконайте команди:
      ```bash
      cd front-end/simple-coffee-front-end
      npm install
      ng serve
      ```
  5. Перейдіть у браузер та в адресному рядку наберіть:
      ```bash
      http://localhost:4200
      ```
